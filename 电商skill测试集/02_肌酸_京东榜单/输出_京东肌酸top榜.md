## 第1步：解析 + 识别品类

- 品类：运动营养·肌酸（一水肌酸类）
- 规格差异 1.6倍 ≥ 1.5倍阈值 → 触发单位价格
- ⚠️ 纯度口径不一：ON"微粉化"、MyProtein"高纯"无具体百分比 → 触发反问

## 第2步：指标选择 + 完整性校验 + 不确定项反问

```
已识别品类：运动营养·肌酸
检测到规格差异（250g~400g），已自动纳入单位价格。

【⚠️ 需你确认的不确定项】（不自行估算）
  - ON"微粉化"、MyProtein"高纯"未给具体纯度百分比，能否提供？
    无法确认则该格标"数据缺失"。
  - 诺特兰德单勺3g，其余5g，单位价格按"元/100g"统一对比即可，是否同意？

【请选择指标】
  1. ✅ 价格（元）↓
  2. ✅ 单位价格（元/100g）↓ ★已自动计算
  3. ✅ 肌酸纯度（%）↑（ON、MyProtein 待确认）
  4. ✅ 总份数（规格÷单勺）↑ ★已自动计算
  5. ✅ 单份价格（元/份）↓ ★已自动计算
  6. ✅ 添加物
默认勾选 1,2,4,5,6。
```

## 第4步：短板定位 + 营销方案

**FoYes 短板**：
- 🔴 单位价格全场最高（56.0元/100g）
- 🔴 单份价格偏高（2.80元/份）
- 🟡 总份数中等（60份）
- ⚪ 溶解度/口感等体验指标缺失

**营销方案**（自动回避价格战，主攻纯度+复合配方）：
- 主标题：99.99% 超纯一水肌酸 + 锌镁协同，比纯肌酸多一层恢复支持
- 副标题：一勺5g标准剂量，给认真训练者的进阶肌酸
- 卖点：①纯度99.99%全场最高 ②锌+镁复合配方独家差异化 ③一勺5g标准剂量 ④10万+好评
- 回避项：不打价格战、不提单份价、不与诺特兰德比性价比
