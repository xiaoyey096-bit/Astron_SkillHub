# 学习计划助手（study-plan-maker）

> **告诉它你想学什么、有多少时间、现在什么水平，5 分钟出一份分阶段、带检查点、可执行的学习计划。**

---

## 核心功能

- **能力树拆解**：把一个学习目标拆成具体的能力模块（如 Python 数据分析拆成 Python基础/NumPy/Pandas/可视化/统计/实战），每个模块标难度和资源类型。
- **时间分配**：按你的每周可用小时，自动分基础/进阶/实战三阶段，每周任务量严格控制在你的时间内（含10%缓冲）。
- **每周任务表**：每周一个主题，下面排具体任务（学什么 + 用什么资源 + 学到什么程度 + 预计耗时）。
- **薄弱点诊断**：结合你的水平，指出最该优先攻克的模块，并设阶段检查点检验成果。

---

## 适用人群

- **自学者**：想系统学一门技能（编程、数据分析、设计），但不知从何开始、怎么安排。
- **备考党**：考研、考证、考公，需要一份分阶段复习计划。
- **转行者**：零基础转新方向，需要一条清晰的路径。
- **给学生/孩子定计划**：家长/老师帮制定学习规划。

---

## 使用流程

1. **说明情况**：学习目标 + 截止日期 + 每周能投入几小时 + 当前水平（也可填 `templates/学习需求采集表.md`）。
2. **自动拆解**：拆能力树、分三阶段、生成每周任务表。
3. **得到计划**：输出计划总览 + 能力树 + 薄弱点 + 每周任务 + 检查点。需要导出任务表为 CSV 说一声。

---

## 使用示例

**输入**：

> 目标：系统学 Python 数据分析，3个月（12周），每周10小时，零基础，喜欢看视频+做练习。

**输出**（节选）：

> **计划总览**：12周，每周10小时（有效9小时），基础5周/进阶4周/实战3周。
> **能力树**：Python基础→NumPy→Pandas→可视化→统计→实战项目。
> **薄弱点**：编程零基础，建议第1-3周重点打 Python 基础，别急着碰数据分析库。
> **第1周任务**：Python 语法与数据类型（视频3h+交互练习2h），过关标准：能独立写一个20行的小程序。
> **检查点**：基础阶段末——能用 NumPy/Pandas 做一次简单数据清洗。

---

## 说明（能力边界）

- **资源只给类型**（视频/文档/习题/项目），不给具体网课或书的链接——因为不联网，无法保证链接有效。你按类型去找对应资源即可。
- **不替你写教学内容**，只规划「学什么、学到什么程度、怎么检验」。
- **不做督学打卡**，计划给你，执行靠你；建议固定学习时段、每周复盘。
