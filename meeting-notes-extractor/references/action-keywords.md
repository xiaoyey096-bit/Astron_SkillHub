# 待办关键词与责任人识别规则（action-keywords）

> 供 `scripts/notes_gen.py extract` 用。识别会议文本中的待办事项（action items）与责任人。

## 一、待办触发关键词

命中以下词的句子，优先作为待办候选：

| 类别 | 关键词 |
|------|--------|
| 任务指派 | 负责、牵头、跟进、推进、落实、执行、去做、来搞、你来、他去 |
| 需求/产出 | 需要、要、得、必须、安排、产出、输出、提交、交付、发送、发一下 |
| 确认/核实 | 确认、核实、查一下、确认下、对一下、核实一下、问一下 |
| 修复/改进 | 修复、修改、调整、优化、改一下、完善 |
| 时间约束 | 下周、本周、月底前、本周五、deadline、截止、之前、之前给到 |
| 决策类 | 决定、确定、敲定、定下来、同意、通过 |

## 二、责任人识别模式

| 模式 | 示例 |
|------|------|
| 「人名 + 负责/去做/跟进」 | 张三负责、李四来跟进 |
| 「需要 + 人名 + 动词」 | 需要张三确认 |
| 「人名 + 你/他去」 | 王五你去沟通 |
| 发言人主动认领 | "我来跟进""我这边负责"（结合上下文发言人） |
| 角色 | 产品、研发、设计、测试、运营（无具体人名时） |

## 三、截止日期识别

| 表达 | 识别为 |
|------|--------|
| X月X日 / X月X号 | 具体日期 |
| 本周X / 下周X | 相对日期 |
| 月底前 / 季度末 | 模糊截止（标"需明确"） |
| 尽快 / 近期 / ASAP | 模糊截止（标"需明确"） |
| X号之前 / X前给到 | 具体截止 |
| 下次会议前 | 相对截止 |

## 四、决议 vs 讨论区分（AI 语义判断，供参考）

| 决议信号 | 讨论信号 |
|---------|---------|
| 决定/确定/敲定/定下来 | 可以考虑/也许/或者 |
| 大家同意/一致认为 | 我觉得/个人感觉 |
| 就这么定了 | 倾向于/建议 |
| 通过/批准 | 需要再看看/再讨论 |

> AI 提炼时严格区分：决议写进「决议」栏，讨论想法写进「讨论要点」栏，绝不把后者当前者。
