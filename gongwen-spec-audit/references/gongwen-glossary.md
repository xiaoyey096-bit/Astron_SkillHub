# 公文规范术语对照表

> 本表用于「规范术语校正」模块（模块④）。列出公文写作中常见的不规范表述及其规范改法。
> 依据：《党政机关公文处理工作条例》《党政机关公文格式》GB/T 9704—2012、GB/T 15834（标点）、GB/T 15835（数字）。
> 表格结构：不规范表述 → 规范表述 → 依据/说明。脚本 `gongwen_toolkit.py glossary` 会自动匹配「不规范表述」列。

## 一、文种使用规范

| 不规范表述 | 规范表述 | 依据/说明 |
|-----------|---------|----------|
| 请示报告 | 请示 / 报告（分清） | 文种不可混用。"请示"用于向上级请求指示批准；"报告"用于汇报工作、反映情况，**报告中不得夹带请示事项** |
| 关于…的申请报告 | 关于…的请示 | 向上级请求批准用"请示"，不用"申请报告" |
| 关于…的汇报 | 关于…的报告 | 正式公文用"报告"，不用"汇报" |
| 函复 | 复函 / 答复 | 规范用语 |
| 通知通报（混用） | 通知 / 通报（分清） | "通知"用于布置工作、告知事项；"通报"用于表彰先进、批评错误、传达重要情况 |

## 二、称谓与敬语规范

| 不规范表述 | 规范表述 | 依据/说明 |
|-----------|---------|----------|
| 你单位 | 贵单位（上行/平行宜用） | 主送上级或平级机关宜用"贵" |
| 贵局（用于下级） | 你局 / ××局 | 对下级不用"贵" |
| 我局/我单位（过多） | 酌情改用全称或"本单位" | 正文首处可用全称，后文可用规范化简称 |
| 各位领导 | （公文不用此称） | 公文主送机关用机关全称或规范化简称，不用"各位领导"等口语化称呼 |

## 三、日期与数字表述

| 不规范表述 | 规范表述 | 依据/说明 |
|-----------|---------|----------|
| 二〇二六年八月二日 | 2026年8月2日 | 成文日期用阿拉伯数字（GB/T 9704—2012 7.3.5.4） |
| 2026年08月02日 | 2026年8月2日 | 月、日不编虚位 |
| 零八年 | 2026年（据实） | 年份标全称 |
| 1日/2日（编虚位） | 1日不写01日 | 月、日不编虚位 |

## 四、量词与计量单位

| 不规范表述 | 规范表述 | 依据/说明 |
|-----------|---------|----------|
| 5块钱 / 5元（口语） | 5元（人民币） | 规范量词 |
| 俩 / 仨 | 两人 / 三人 | 公文不用口语量词 |
| 公分 / 公尺 | 厘米 / 米 | 用法定计量单位（GB 3100） |
| 斤（正式文件涉及精确量） | 千克/克 | 法定计量单位 |

## 五、过时套语与冗余表述

| 不规范表述 | 规范表述 | 依据/说明 |
|-----------|---------|----------|
| 兹有…请予查收 | 现将…送上，请查收 | 现代规范表述 |
| 收悉（用于开头套话过多） | 酌情精简 | 公文宜开门见山 |
| 关于…事宜（结尾"特此通知"滥用） | 酌情删减 | "特此通知""特此报告"等并非必须，避免滥用 |
| 为此，特作如下通知 | 直接陈述要求 | 避免冗余过渡语 |
| 现将有关事项通知如下（开头） | 可保留或精简 | 视情况，避免千篇一律 |

## 六、标点符号规范（GB/T 15834）

| 不规范表述 | 规范表述 | 依据/说明 |
|-----------|---------|----------|
| 半角冒号 ": " | 全角冒号 "：" | 公文中"主送机关后""签发人后"用全角冒号 |
| 半角括号 ( ) | 全角括号 （ ）用于层次序号 | 层次序号"（一）"用全角 |
| 方括号 [2026] | 六角括号 〔2026〕 | 发文字号年份用六角括号〔〕（GB/T 9704—2012 7.2.5） |
| 连续句号 。。。 | 一个句号 。 | 不叠用句号 |
| 一逗到底（长句无句号） | 适当断句用句号 | 公文长句宜分段断句 |

## 七、口语化与不规范用语

| 不规范表述 | 规范表述 | 依据/说明 |
|-----------|---------|----------|
| 搞好 / 抓一下 | 做好 / 抓好 | 规范动词 |
| 想办法 | 采取措施 | 规范表述 |
| 大家都知道 | （删去） | 避免口语化插入语 |
| 基本上 / 差不多 | 基本上（公文慎用模糊词） | 表述宜明确 |
| 一定要 / 必须要 | 应当 / 要 | 规范助动词 |

## 使用说明

- 脚本 `gongwen_toolkit.py glossary <文件>` 会逐行扫描，匹配「不规范表述」列，输出每处位置 + 规范改法 + 依据。
- AI 在调用时可结合上下文判断（如"贵局"对下级才不规范，对上级/平级是规范的），对脚本结果做语义复核。
- 本表为常见项，非穷尽；用户可自行扩充 `references/gongwen-glossary.md`。
