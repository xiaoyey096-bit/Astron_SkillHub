# 通用对比维度提取规则（dimension-extract）

> 供 `scripts/doc_compare.py parse/matrix` 用。从文档中识别可对比的维度（行）。
> 维度来源：①文档自带的小标题/列表项；②命中通用维度关键词库。

## 一、通用对比维度关键词库

按维度归一（不同表述归到同一维度）：

| 规范维度 | 命中关键词（任一即归此维度） |
|---------|---------------------------|
| 价格 | 价格、售价、费用、收费、定价、多少钱、元/月、免费、付费、套餐 |
| 功能 | 功能、支持、特性、能力、可以、提供、模块 |
| 规格 | 规格、参数、尺寸、重量、容量、版本、配置 |
| 性能 | 性能、速度、延迟、并发、吞吐、响应时间 |
| 兼容性 | 兼容、支持系统、平台、Windows、Mac、Linux、iOS、安卓 |
| 易用性 | 易用、操作、上手、界面、简单、复杂 |
| 安全 | 安全、加密、隐私、合规、认证 |
| 服务/支持 | 售后、客服、支持、服务、保障、 warranty |
| 优点 | 优点、优势、亮点、长处、好处 |
| 缺点 | 缺点、不足、劣势、短板、限制、问题 |
| 适用对象 | 适用、适合、面向、目标用户、人群 |
| 评价 | 评分、好评、口碑、推荐、评价 |

## 二、维度提取策略

1. **优先用文档结构**：若文档有小标题（`##`/`**XX：**`/`1. XX`），直接作为维度候选；
2. **关键词兜底**：无明确结构的，按关键词库扫描，命中即提取该维度；
3. **归一**：不同文档的"价格""售价"归到同一行；
4. **取并集**：所有文档涉及维度的并集作为对比矩阵的行。

## 三、矩阵单元格填充

- 该文档在该维度有内容 → 填原文摘要（精简，保留关键信息）；
- 该文档未涉及该维度 → 填「未提及」（绝不脑补或借用其他文档内容）；
- 多次提及 → 合并为一条。

> 维度归类由脚本给候选，AI 做最终归一判断（处理同义、口径统一）。
