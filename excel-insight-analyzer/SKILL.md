# Excel/CSV 数据智能分析与洞察助手（excel-insight-analyzer）

> 中文技能名：**数据洞察助手**
> 定位：把「一份看不懂的原始数据表」变成「一份有结论、有建议、有图选型的分析报告」。不联网、不调外部模型、本地纯标准库运行。

本文件是 AI 调用入口。当用户触发以下任一场景时应加载本 Skill，并按下面的标准工作流程（SOP）执行。

> **能力边界（重要）**：本 Skill 只做**对用户已提供的数据表进行统计与洞察分析**。**不具备**：联网采集外部数据、连接企业数据库、NL2SQL 直查数据库、预测建模/机器学习建模、生成真实图表图片（只给图表选型与绘图建议，不渲染二进制图）。

---

## 一、核心原则（不可违反）

1. **只用用户给的数据**：所有结论必须基于用户上传/粘贴的表格数据。数据里没有的字段，一律不臆测、不补「行业均值」。无法支撑的结论直接说「数据不足，无法判断」。
2. **统计交给脚本，洞察交给 AI**：数值统计（均值/分位数/异常值标记）这类**确定性计算**必须调用 `scripts/analyze.py` 完成，保证可复现、不口算出错；趋势解读、对比归因、建议这类**语义判断**由 AI 基于统计结果产出。
3. **异常检测双法互证**：数值型字段的异常值同时用 IQR 法与 Z-score 法检测，**仅当两种方法都命中**才标为「高置信异常」，单一命中标「待复核」，避免误报。
4. **分类型不强行套数值法**：分类型/文本型字段不做均值/分位数，只做频次、唯一值、占比。混用会出错。
5. **不渲染图片**：只输出 Mermaid / 文本表格形式的图表选型建议与可复制绘图代码，不生成 PNG/SVG 二进制。

## 二、何时加载本 Skill（触发与边界）

当用户请求命中下面**任一**场景时加载：

| 场景关键词 | 对应能力 |
|-----------|---------|
| "分析/看看/解读"一份 Excel/CSV/表格数据，要结论 | 数据概览 + 描述统计 + 洞察 |
| "找出异常/哪个不对劲/有没有离谱的值" | 异常值检测 + 归因 |
| "数据说明了什么/给我一份报告/数据洞察" | 全流程分析报告 |
| "指标异动/波动原因/为什么降了" | 异常归因（需时间或分组维度） |

**不应加载**的情况（避免跨场景误触发）：
- 用户要"连数据库查""实时取数""NL2SQL" → 本 Skill **不连数据库**，告知超出范围；
- 用户要"预测未来趋势/做机器学习模型" → 本 Skill **不做预测建模**，告知超出范围；
- 用户给的是纯文本段落（非表格结构）且只要求"总结这段话" → 不加载，按普通摘要处理。

## 三、标准工作流程（SOP）

### 第 1 步：接收并解析数据

**输入形式**（任一）：
- 文件路径：`.csv` / `.xlsx` / `.xls`（`.xlsx/.xls` 由脚本读取，依赖 `openpyxl`，未安装则提示用户另存为 CSV 或粘贴文本）；
- 粘贴的表格文本：Markdown 表格、TSV（制表符分隔）、逗号分隔、逐行列出的键值。

**解析动作**：
1. 读取为行列结构，识别表头（首行）与数据行。
2. 逐列判断字段类型：**数值型 / 日期型 / 分类型 / 文本型**（类型识别规则见 `references/field-type-rules.md`）。
3. 统计每列缺失值数量与缺失率；数值列额外统计基础量纲（最小、最大、量纲差异）。
4. **歧义确认闸**（一次性反问，不打断多次）：
   - 若某列既像数值又像分类（如 "≥18""约200"），询问"按数值还是分类处理"；
   - 若表头缺失或有多行表头，询问哪一行是真正表头；
   - 若存在明显的"业务主键/ID列"（如订单号、工号），询问是否排除出统计。

调用脚本：`python scripts/analyze.py profile <文件路径>` → 输出 JSON 概览。

### 第 2 步：描述统计 + 异常检测

对**数值型**字段调用：`python scripts/analyze.py stats <文件路径>`，得到：
- 描述统计：计数、均值、中位数、标准差、最小值、最大值、Q1/Q3、缺失数；
- 异常值：IQR 法（`< Q1-1.5×IQR` 或 `> Q3+1.5×IQR`）与 Z-score 法（`|z|>3`）双法命中的行号与值，并标注「高置信异常 / 待复核」。

对**分类型**字段调用：`python scripts/analyze.py freq <文件路径>`，得到唯一值数、Top 频次与占比。

> 统计结果中所有用户数据写入报告前，统一经脚本内 `sanitize_cell()` 净化（防破坏 Markdown 表格结构、防公式注入）。

### 第 3 步：洞察提炼（AI 语义层，基于第 2 步结果）

AI 基于统计结果，按下列维度产出**数据支撑的洞察**（每条洞察必须能指回某行统计或某组数值）：

- **趋势**：若数据含时间/序号维度，指出上升/下降/波动的字段及幅度；
- **对比**：若数据含分组维度，对比组间差异，标出显著领先/落后的组；
- **异常**：高置信异常值点出具体行与值，给出可能的业务解读（如"疑似录入错误""真实业务高峰"），但**不下死结论**，标「需结合业务核实」；
- **结构/占比**：分类字段的 Top 占比、集中度（如某类占 70% 说明结构高度集中）；
- **相关性提示**：两个数值列若肉眼可见同向/反向变化，提示"可能相关，建议进一步验证"，不计算相关系数（避免小样本误导）。

### 第 4 步：可视化图表选型建议

根据数据特征推荐**最合适的 1-3 种图表**（不渲染，只给选型理由 + 可复制的 Mermaid 代码或绘图建议）：

| 数据特征 | 推荐图表 |
|---------|---------|
| 时间序列数值 | 折线图 |
| 分类 × 数值对比 | 柱状图（分类多时改横向条形） |
| 占比/结构 | 饼图（≤5 类）或 Treemap 文本描述 |
| 分布形态 | 直方图 / 箱线图（尤其配合异常检测） |
| 两数值关系 | 散点图 |

输出包含 Mermaid 可直接渲染的示例（如折线、柱状），用户复制即可在支持 Mermaid 的环境查看。

### 第 5 步：输出分析报告

按 `templates/analysis-report-template.md` 输出，结构固定：
1. **数据概览**（行列数、字段清单及类型、缺失情况）；
2. **描述统计表**（数值字段统计；分类字段频次）；
3. **异常值清单**（行号、字段、值、置信度、业务解读）；
4. **关键洞察**（编号列表，每条有数据支撑）；
5. **可视化建议**（图表选型 + Mermaid 代码）；
6. **数据质量提示与局限**（缺失率高的列、样本量是否足以支撑结论、未覆盖的维度）。

默认在对话区以 Markdown 呈现。用户要求"导出"时，输出经 sanitize 的 CSV 文本（如把异常值清单导成 CSV），用户粘贴到 Excel/WPS 即可，不生成二进制文件。

## 四、输入输出约定

- **输入**：文件路径或粘贴表格文本。`.xlsx/.xls` 优先用脚本读取；粘贴文本由 AI 规整后落成临时 CSV 交脚本处理。
- **输出**：Markdown 分析报告（含表格、Mermaid 图代码）；表格动态字段已 sanitize。
- **语言**：中文，结论优先用大白话，统计术语括注解释（如"中位数（去掉极端值后的中间值）"）。

## 五、异常与边界情况处理清单（鲁棒性保障）

| 异常情况 | 处理方式 |
|---------|---------|
| 空文件 / 仅表头无数据 | 报告"无数据行"，不强行分析 |
| 全部分类列、无数值列 | 跳过描述统计与异常检测，只做频次/占比洞察 |
| 缺失率 > 50% 的列 | 在报告中显著提示"该列数据质量差，结论慎用"，不删除但降权 |
| 某列类型识别为数值但实际是 ID/编码（如 20230101 形式的日期数字） | 经歧义确认闸，按日期或分类处理，不当数值算均值 |
| 极端值把均值拉飞 | 同时报告均值与中位数，并提示"均值受极端值影响，参考中位数" |
| 样本量 < 30 | 提示"样本量较小，统计结论仅供参考" |
| `.xlsx` 依赖 openpyxl 未安装 | 提示用户另存为 CSV 或粘贴文本，不报错中断 |
| 多 Sheet 文件 | 列出 Sheet 名让用户选一个，默认分析第一个 |
| 用户数据含中文表头/特殊字符 | sanitize_cell 统一处理，不破坏表格 |
| 用户要求"预测下个月""建个模型" | 告知超出能力边界，仅给出基于历史数据的趋势描述 |
| 用户要求"连我的数据库取数" | 告知不联网不连库，请其导出数据表后提供 |
| 文本含 `=` `+` `-` `@` 开头（CSV 注入风险） | sanitize 时前置单引号 |

## 六、结果验收标准

- 对 `samples/销售明细.csv`（含数值/日期/分类三类字段、含已知异常值）执行全流程，应：
  1. 正确识别三类字段类型，无误判；
  2. 数值字段统计量准确（可手动抽验均值/中位数）；
  3. 检出预设的异常值且标「高置信异常」；
  4. 输出 ≥3 条有数据支撑的洞察；
  5. 给出 ≥1 个匹配数据特征的图表选型。
- 对全分类列的 `samples/客户分布.csv`，应跳过数值统计、只做频次占比，不报错。

测试命令：`python tests/run_test.py`。

## 七、不应该做什么（边界与合规）

1. **不联网、不连数据库**：全程本地处理用户已提供的数据表，不调用任何外部 API 或模型。
2. **不预测建模**：不做回归预测、不做机器学习、不算相关系数下因果结论。
3. **不编造数据**：分析里出现的每个数字都必须来自用户数据或其上的统计计算；缺失项标「数据不足」，不用「行业均值」补。
4. **不生成图片**：只给图表选型与 Mermaid 文本代码，不渲染 PNG/SVG。
5. **不外传数据**：用户数据仅用于本次分析，不存储不外传；数据含个人信息（姓名/手机/身份证）时提醒脱敏。
6. **不强行套方法**：分类字段不做数值统计；小样本不放大结论。
