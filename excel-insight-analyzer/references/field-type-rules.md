# 字段类型识别规则（field-type-rules）

> 本文件供 `scripts/analyze.py` 与 AI 共同参照，统一「数值 / 日期 / 分类 / 文本」四类的判定标准与歧义处理。

## 一、四类字段定义

| 类型 | 判定条件（满足即归入） | 典型示例 |
|------|----------------------|---------|
| **数值型** | 列中 ≥80% 的非空单元格能解析为纯数字（含小数、负数、千分位、百分号去除后） | 销售额、单价、年龄、评分 |
| **日期型** | 列中 ≥80% 的非空单元格匹配常见日期格式（见下） | 订单日期、注册时间、生日 |
| **分类型** | 唯一值数量 ≤ 总行数的 50%，且非数值非日期 | 性别、地区、商品类目、状态 |
| **文本型** | 兜底类型：既不是数值/日期/分类的自由文本 | 备注、地址、描述 |

## 二、常见日期格式（命中其一即按日期解析）

- `2026-08-03` / `2026/08/03` / `2026.08.03`
- `2026年8月3日`
- `20260803`（8 位紧凑数字日期，**注意：纯数字 8 位易与"数值"混淆，需先尝试日期解析**）
- `2026-08-03 14:30:00` / `08/03/2026`
- 时间戳（10 位秒 / 13 位毫秒，需结合范围判断）

## 三、歧义处理（关键，决定统计正确性）

以下场景**不能自动定论**，须触发「歧义确认闸」由用户拍板：

1. **"数字 ID" vs "数值"**：如订单号 `20230101567`、身份证号、工号——看起来是数字，但求均值无意义。
   - 启发：字段名含"号/ID/编码/编号"，或唯一值数 = 非空数（每行都不同）。
   - 默认倾向：当**分类**处理（频次），不做数值统计。
2. **"带修饰词的数值"**：如 `≥18`、`约200`、`<0.05`、`1.2万`。
   - 提取数字主体参与统计，保留修饰标注；若修饰占比高，询问"是否仍按数值处理"。
3. **"日期数字" vs "数值"**：如 `20260803`。
   - 先尝试按日期解析，解析成功率高则归日期；否则归数值。
4. **"百分比" vs "小数"**：`50%` 归数值 0.5，但需在报告中注明"已把百分比换算为小数"。
5. **"二值字符串"**：`是/否`、`成功/失败`、`男/女`——归分类，必要时可提示用户编码为 0/1 再做统计。

## 四、类型识别后的统计分工

| 类型 | 允许的统计 | 不允许的统计 |
|------|-----------|-------------|
| 数值型 | 计数、均值、中位数、标准差、分位数、极值、异常检测 | 频次 Top（除非唯一值很少） |
| 日期型 | 最早/最晚、跨度天数、按月/季聚合计数 | 均值（无意义） |
| 分类型 | 唯一值数、频次 Top、占比 | 均值、异常检测 |
| 文本型 | 非空数、平均字数（可选） | 其他数值统计 |

> **核心防错**：分类型字段绝不做均值/分位数，数值型字段绝不做频次占比当主结论。这是最常见的分析错误。
