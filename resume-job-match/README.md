# 人岗匹配助手（resume-job-match）

> **贴一份简历 + 一份岗位 JD，30 秒给出匹配度评分、逐条差距清单和"怎么补"的可执行建议——求职者投前自检、HR 批量筛简历都好用。**

---

## 核心功能

- **双向匹配评分**：硬性条件一票否决 + 五维加权打分（学历/年限/核心技能/项目相关性/加分项），分数有依据、可解释，不虚高不压分。
- **逐条差距诊断**：JD 要求逐条比对，分 ✅命中 / 🟡部分 / 🔴缺失 / ⚪未提及，硬性缺失置顶标红，一眼看清差在哪。
- **可执行建议**：不只说"缺 X"，还给"怎么补"（求职者补强方向 + 埋没亮点重写）和"是否可放宽"（HR 视角的不必要门槛）。
- **批量筛选排序**：1 个 JD 对多份简历，一键按匹配度排序，输出是否建议进入面试的总表。

---

## 适用人群

- **求职者**：投递前自检匹配度，知道差在哪、简历往哪个方向补强，避免海投石沉大海。
- **HR / 招聘者**：批量筛简历排序，快速定位高匹配候选人，识别哪些硬性门槛可能漏掉合适人选。
- **猎头**：人岗撮合，给候选人客观的匹配度参考。

---

## 使用流程

1. **提供简历和 JD**：粘贴文本或上传 `.txt`/`.md`/`.docx`（手机号邮箱自动脱敏）。
2. **确认要素**：自动抽取双方结构化要素，遇到歧义（如年限怎么算、某条是硬性还是加分）一次性确认。
3. **生成报告**：输出匹配度总览 + 评分明细 + 差距清单 + 优化建议。批量模式给排序总表，需要导出 CSV 说一声。

---

## 使用示例

**输入**（简历节选 + JD 节选）：

> 简历：张伟，5 年 Java 后端，本科，Spring Boot/Spring Cloud/MySQL/Redis/Docker/K8s，有订单交易微服务平台经验。
> JD：高级 Java 后端，本科及以上，3 年以上，精通 Java + Spring，熟悉 MySQL/Redis，有 Spring Cloud 经验（加分：Docker/K8s/Kafka）。

**输出**（自动生成，节选）：

> **综合匹配度：92%　高度匹配　硬性条件全部通过**
>
> **评分明细**：核心技能覆盖 100%（必备 6/6 全命中）、年限 100%（5 年 ≥ 3 年）、加分项命中 Docker/K8s。
>
> **差距清单**：✅ Java/Spring/MySQL/Redis/Spring Cloud 全部命中；🟡 Kafka——简历项目提了但技能区未单列，建议补到技能区。
>
> **建议**：Kafka 经验埋没在项目描述里，提到技能区可进一步提升匹配度；现有微服务平台项目已强力支撑 JD 的"微服务实际经验"硬性要求。

## 数据说明

- **只看你给的文本**：简历/JD 没写的字段标「未提及」，不臆测、不默认、不查外部薪酬库。
- **PII 自动脱敏**：手机号 `138****5678`、邮箱 `z***@`，数据不存储不外传。
- **客观中立**：每分都有依据，硬性不满足直接判不通过，不为讨好任何一方改分。

---

## 能力边界

本助手**只做**对已提供简历与 JD 的匹配诊断。**不做**：联网抓取招聘信息、对接企业 ATS、背景调查、自动投递、生成完整新简历（只给优化方向）。
