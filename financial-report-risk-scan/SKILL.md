# 金融材料风险信号扫描与摘要助手（financial-report-risk-scan）

> 中文技能名：**年报风险扫描助手**
> 定位：把「一份冗长的金融材料文本」变成「一份关键数据 + 分级风险信号的风险摘要」。降低金融材料理解门槛、提升风险识别效率。纯本地运行、不联网、不调外部模型。

本文件是 AI 调用入口。当用户触发以下任一场景时应加载本 Skill，并按下面的标准工作流程（SOP）执行。

> **能力边界（极重要）**：本 Skill 只做**对用户提供的金融材料文本进行数据抽取、风险信号提示与摘要**，定位是「阅读辅助 + 风险提示工具」。**不构成投资建议、不做买卖推荐、不认定财务造假、不替代专业审计与投顾**。所有风险信号均为「提示关注」，最终判断由专业人士做出。

---

## 一、核心原则（不可违反）

1. **忠于原文、不编造**：抽取的每个数据、每个风险点都必须来自用户提供的材料文本。材料里没有的数字不能补，不能推测"大概是多少"。
2. **风险信号≠结论**：识别出的风险信号一律表述为「提示关注」，不下"该公司有问题""财务造假""会暴雷"等定性结论。只摆事实（原文数据/表述）+ 提示（这类信号通常值得关注）。
3. **不构成投资建议**：绝不输出"建议买入/卖出/持有"等投资指令。
4. **数据抽取交给脚本，语义判断交给 AI**：财务数字、风险关键词这类**模式化抽取**调用 `scripts/risk_scan.py`；风险因素的语义归纳、趋势判断由 AI 基于抽取结果产出。
5. **缺失数据如实标注**：材料里没披露的字段标「未披露」，不用「行业均值」填充。

## 二、何时加载本 Skill（触发与边界）

当用户请求命中下面**任一**场景时加载：

| 场景关键词 | 对应能力 |
|-----------|---------|
| "分析/看/解读"年报、财报、招股书 | 数据抽取 + 风险摘要 |
| "风险/风险点/风险信号"识别 | 风险信号扫描 |
| "对比/趋势"多份财报 | 多期对比（需提供多期数据） |

**不应加载**的情况：
- 用户要"推荐我买哪只股票" → 本 Skill **不做投资建议**；
- 用户要"判断这家公司有没有财务造假" → 本 Skill **不做造假认定**，只提示风险信号；
- 用户给的是实时行情/盘口数据 → 本 Skill 处理的是材料文本，非实时行情。

## 三、标准工作流程（SOP）

### 第 1 步：接收并解析材料

**输入形式**（任一）：
- 金融材料文本：年报/财报/招股书/审计报告/研究报告/信贷材料（粘贴文本或 `.txt`/`.md` 文件路径）；
- 用户手动整理的关键数据（如"营收5亿，净利润-2000万"）。

**解析动作**（调用 `python scripts/risk_scan.py extract <文件>`）：
- 识别材料类型（年报/财报/招股书/审计报告等，按标题关键词）；
- 抽取关键财务数据（营收、净利润、总资产、负债、经营性现金流等，带金额与单位）；
- 定位"风险因素""重要事项""关联交易"等章节。

### 第 2 步：风险信号扫描

调用 `python scripts/risk_scan.py risk <文件>`，按 `references/risk-signals.md` 规则库扫描：
- **财务风险信号**：营收同比下滑、净利润亏损/亏损扩大、负债率偏高、经营性现金流为负、应收账款激增等；
- **非财风险信号**：审计非标意见（保留/无法表示）、重大诉讼/担保、关联交易占比高、高管频繁变动、被监管处罚等。

每个风险信号标 🔴高/🟡中/🟢低 关注度（按规则库定义）。

### 第 3 步：AI 语义归纳

AI 基于抽取的数据和风险信号，做：
- **风险摘要**：用 2-3 句话概括这份材料最值得关注的点；
- **趋势判断**（若有多期数据）：指出哪些指标在恶化/改善；
- **交叉印证**：如"净利润为正但经营性现金流为负"这类需结合看的信号。

### 第 4 步：输出风险摘要报告

按 `templates/risk-report-template.md` 输出，结构固定：
1. 材料概览（类型、主体、报告期）；
2. 关键财务数据表；
3. 风险信号清单（分级，每条含信号+原文依据+提示）；
4. 风险摘要（AI 归纳）；
5. 局限与免责声明。

默认在对话区呈现 Markdown。用户要求导出时输出经 sanitize 的 CSV（如关键数据表）。

---

## 四、输入输出约定

- **输入**：金融材料文本（文件路径或粘贴）。
- **输出**：Markdown 风险摘要报告；表格动态字段经 `sanitize_cell()`；数字与单位保留原文。
- **语言**：中文，财务术语规范。

---

## 五、异常与边界情况处理清单（鲁棒性保障）

| 异常情况 | 处理方式 |
|---------|---------|
| 材料为空或太短 | 报告"内容不足" |
| 非金融材料（误传） | 提示"未识别到典型金融材料特征，请确认" |
| 关键数据缺失 | 标「未披露」，不编造 |
| 数字单位不统一（元/万元/亿元） | 尝试归一化并标注换算，无法确定则保留原文 |
| 多期数据混在一起 | 询问/按年份分组后分别抽取 |
| 文本含表格被压成乱序 | 尽量按上下文还原，无法还原的标"数据可能错位，需核对" |
| 风险信号命中但上下文表明是改善 | AI 标注"此项为改善中的信号，关注度降低" |
| 用户问"能买吗" | 明确不做投资建议 |
| 用户问"是不是造假" | 明确不做造假认定，只列已识别的风险信号供参考 |
| 文本含特殊字符 | sanitize_cell 净化 |

## 六、结果验收标准

- 对 `samples/年报样例-含风险.txt`（含营收下滑、亏损、现金流为负、诉讼担保）：应抽取≥4项关键数据、识别≥3条风险信号（至少1条🔴高）、输出风险摘要与免责声明。
- 对 `samples/年报样例-健康.txt`（业绩良好）：应报告"未发现重大风险信号"，不凑数、不编造风险。
- 不出现"建议买入/卖出""财务造假"等违规表述。

测试命令：`python tests/run_test.py`。

---

## 七、不应该做什么（边界与合规）

1. **不构成投资建议**：不输出买卖持有指令。
2. **不做造假认定**：只提示风险信号，不下造假结论。
3. **不编造数据**：材料没有的标「未披露」。
4. **不替代专业服务**：不替代审计师、投顾、风控专业判断。
5. **不联网**：不查实时行情、不调外部数据接口、不调外部模型。
6. **不遗漏免责**：每份报告必须含免责声明（辅助参考，非投资/审计依据）。

## 八、文件说明

- `references/risk-signals.md`：风险信号识别规则库（财务/非财，分高/中/低）。
- `templates/risk-report-template.md`：风险摘要报告输出模板。
- `samples/`：测试样例（含风险、健康各一份）。
- `scripts/risk_scan.py`：扫描脚本，子命令 `extract`/`risk`，纯标准库，内置 `sanitize_cell()`。
- `tests/run_test.py`：一键自测。
- `README.md`：完整使用说明。
