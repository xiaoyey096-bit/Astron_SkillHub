# 金融风险信号识别规则库（risk-signals）

> 供 `scripts/risk_scan.py risk` 用。每条信号含：信号名、命中模式、风险等级、提示语。
> 命中即报，AI 结合上下文标注是否为"改善中的信号"。

## 一、财务风险信号

### 1. 营收下滑（🔴高）
- **模式**：营收/营业收入 + 同比 + 下降/下滑/减少（百分比）
- **提示**：营收同比下滑，关注主业是否承压、是否行业性衰退。

### 2. 净利润亏损/亏损扩大（🔴高）
- **模式**：净利润 + 亏损/为负；或 亏损 + 扩大/增加
- **提示**：净利润为负或亏损扩大，关注盈利能力与持续经营。

### 3. 经营性现金流为负（🔴高）
- **模式**：经营活动(产生的)?现金流(量)?净额 + 负/为负/-
- **提示**：经营性现金流为负，关注利润质量（是否有现金支撑）。

### 4. 负债率偏高（🟡中）
- **模式**：资产负债率 + 高于70%（或具体数值≥70）
- **提示**：资产负债率偏高，关注偿债压力。

### 5. 应收账款激增（🟡中）
- **模式**：应收账款 + 同比 + 增长 + 大幅/激增（或增速远超营收）
- **提示**：应收账款激增且快于营收，关注回款风险与收入质量。

### 6. 存货激增（🟡中）
- **模式**：存货 + 同比 + 大幅增长/激增
- **提示**：存货大幅增长，关注滞销与减值风险。

### 7. 毛利率大幅下滑（🟡中）
- **模式**：毛利率 + 下降 + X个百分点
- **提示**：毛利率下滑，关注成本压力或竞争加剧。

## 二、非财务风险信号

### 8. 审计非标意见（🔴高）
- **模式**：保留意见 / 无法表示意见 / 否定意见 / 带强调事项段
- **提示**：审计意见非标准无保留，高度重视，可能涉及重大不确定性。

### 9. 重大诉讼（🟡中）
- **模式**：诉讼/起诉/纠纷 + 金额
- **提示**：存在重大诉讼，关注潜在赔付与声誉影响。

### 10. 对外担保（🟡中）
- **模式**：对外担保/担保余额 + 金额
- **提示**：对外担保金额较大，关注或有负债风险。

### 11. 关联交易占比高（🟡中）
- **模式**：关联交易 + 占比/金额大
- **提示**：关联交易规模较大，关注公允性与利益输送风险。

### 12. 高管变动频繁（🟢低）
- **模式**：董事长/总经理/财务总监 + 辞职/离任/变动
- **提示**：核心高管变动，关注经营稳定性。

### 13. 被监管处罚/立案（🔴高）
- **模式**：立案调查/监管处罚/警示函/行政处罚
- **提示**：被监管立案或处罚，高度重视合规风险。

### 14. 持续经营存疑（🔴高）
- **模式**：持续经营 + 重大不确定性/存疑
- **提示**：持续经营能力存疑，高度关注。

## 等级说明
- 🔴 高：通常涉及盈利、现金、审计、合规等核心风险，优先关注。
- 🟡 中：需结合程度与趋势判断，值得关注。
- 🟢 低：提示性，单独存在不一定构成重大风险。

> 命中后 AI 必须结合上下文判断：若原文表明该项正在改善（如"亏损收窄"），应降低关注度并说明。
