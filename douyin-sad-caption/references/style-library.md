# 伤感文案风格库（style-library）

> 本文件是生成流程的「句式弹药库」。AI 在流程 A 第 2 步从这里挑 2-3 种句式，保证多版备选风格不重复。
> 本 Skill 不联网，所有风格规则沉淀在本文件，输出稳定可复现。

---

## 〇、最高原则：隐隐表达（凌驾于所有规则之上）

> 高级伤感文案的核心是"不明说"。把情绪藏进意象/典故/数字里，让读者自己悟。
> 直白点破"人没了/不在了/失去" = 失败文案，必须重写。

### 0.1 绝对禁止的"太明显"写法（反面教材）

| ❌ 错误 | 为什么错 | ✅ 正确 |
|--------|---------|--------|
| "人不在了/人没了/你不在了" | 把失去直白点破，尴尬廉价 | 用隐喻：刻舟求剑、空座位、没喝完的茶 |
| "对面那个人不知道什么时候就没了" | 又长又直白解释悲剧 | 朴素陈述："每次喝奶茶都有你" |
| "观众只剩自己/连回声都没有" | 把孤独说得太满 | 反转结构："只要有你一个人就够了" |
| "没事/不在乎"单独成句 | 太短太浅无信息 | 用可解读意象："十点差三分" |

### 0.2 隐隐表达的 4 种手法（生成时优先用这些）

**手法①：典故/成语** —— 用一个四字成语替代整段解释。
- 「故地重游就像**刻舟求剑**」——明知回不去还在原地标记。
- 「想你的夜里**秉烛夜游**」——不直接说想你。

**手法②：反转结构（宏大↔微小）** —— 用数量/范围的极端对比制造张力。
- 「想证明给**一万个人**看，到后来……只要有**你一个人**就够了。」
- 「走过**万千灯火**，最亮的是**你家那盏**。」

**手法③：数字/时间意象** —— 用具体数字或时间制造可解读的密码感。
- 「都说了**十点差三分**」——21:57 = 爱你无期。
- 「等了**37个红绿灯**，还是没等到你。」
- 「**三月零七天**，我学会了一个人吃饭。」

**手法④：朴素陈述句** —— 不解释、不渲染，把最重的话说得最轻。
- 「不是因为奶茶，是因为**每次喝奶茶都有你**。」
- 「你走后，我**还是点两杯**。」

### 0.3 扩充填空任务（用户给"【____】"）的字数与选材

- 填入长度**匹配骨架句式**（见 SKILL.md 原则3）：短古风骨架填 4-8 字对仗；长白话骨架可填完整句。
- **关键：隐隐程度要匹配骨架朴素度**——这是最容易犯的错：
  - 骨架是**口语化白话**（如"人好像丢了某种东西后，___""在看透一切的时候，失去或许___"）→ 答案也要**朴素直白**（如"就不爱说话了""比拥有更踏实"），**不要硬塞文艺意象**，否则割裂。
  - 骨架是**古风/文学化**（如"愿许秋风离别意，___""晚风吹人醒，___"）→ 答案才配古雅四字/对仗（如"散我心中意难平""万事藏于心"）。
  - **反面教材**：第2题骨架是白话，标准答案"就不爱说话了"很朴素，但盲测给了"开始写日记了/说话留半句"——过度文艺，反而不如朴素答案走心。
- **禁止**填一长串解释性句子（如"是因为对面那个人不知道什么时候就没了"——太长太满）。
- **禁止**只填 2-3 个浅情绪词（如"没事"——太短无信息）。

### 0.4 按骨架句式选填法（关键查表）

填空前先看骨架是什么句式，对应不同填法：

| 骨架句式 | 填法 | 示例（骨架→答案） |
|---------|------|-----------------|
| "X是___"（缘分是/爱是/孤独是） | **比喻定义句**：填"本体+延伸描述"的长句，常带排比 | 缘分是→本书，翻得太快会错过，读的太认真，又流泪 |
| "只是___"（你从不缺人陪，只是___） | **具体场景/时间状语**，不要抽象概念 | 只是→在无聊的时候想起我（不是"缺那个对的人"） |
| "直到___" | 宏大意象 或 朴素时间词 | 直到→它成为回忆 / 直到世界的尽头 |
| "或许___" | 朴素陈述承接基调 | 或许→太喜欢和无奈（复合情绪也可） |
| "成为___" | 单个名词，越克制越好 | 成为→遗憾 |
| 古风半句（愿许…/晚风…） | 古雅四字/对仗句 | 晚风吹人醒→万事藏于心 |
| "为什么___却不能___"（古文题） | 真实古诗词名句 | →一种相思，两处闲愁 |

### 0.5 自检闸（每条文案生成后必过）

念出来听众是**起鸡皮疙瘩**（隐隐戳中）还是**觉得尴尬**（说太满）？觉得尴尬就重写。
**追加自检**：填空后整句念一遍，如果填入部分和骨架"文白割裂"（白话骨架配了古雅词，或古风骨架配了大白话），重写到协调。

## 一、三种核心语气（多版备选必须至少覆盖两种）

### 1. 克制留白
特点：短句、断句多、话不说满，靠**意象**留白让读者自己补画面（注意：不直白写"没人/不在了"，见第0原则）。
- 句式模板：「<一个动作>。<一个意象>。」
- 句式模板：「<场景>，<轻描淡写的细节>。」
- 示例：「钥匙转了两圈。第二把钥匙，再没人用过。」（用"第二把钥匙没人用"代替"人不在了"）
- 示例：「把灯全打开，茶杯摆了两个。」（用"两个茶杯"暗示，不点破）

### 2. 破防直给
特点：情绪直接给到，用一个反差或反问击中读者。
- 句式模板：「<看似平常的事>，<才发现有多难>。」
- 句式模板：「以为<期待>，其实<真相>。」
- 示例：「最难的不是离开，是假装没事。」
- 示例：「以为熬过去就好了，原来只是习惯了。」

### 3. 治愈反转
特点：前半句低落，后半句轻轻接住，给一点暖。
- 句式模板：「<低落>，但<一个小确幸>。」
- 句式模板：「<承认难>，<一句温柔的话>。」
- 示例：「也会一个人走夜路，也会有路灯为我亮着。」
- 示例：「哭也没关系，明天还是要好好吃饭。」

## 二、常用情绪内核标签（流程 A 第 1 步用）

从用户输入提炼下列标签之一，写到内部思考，决定走哪种语气：

| 情绪内核 | 推荐语气 | 适配画面元素 |
|---------|---------|------------|
| 孤独 | 克制留白 | 空房间、单把椅子、路灯、影子 |
| 怀念 | 破防直给 | 老照片、旧物、雨天、车窗 |
| 落差感 | 破防直给 | 人群、热闹场景里的一个人 |
| 不被理解 | 克制留白 | 逆光、背影、没发出的消息 |
| 失去 | 治愈反转 | 落叶、空座位、远去的车 |
| 疲惫 | 治愈反转 | 深夜、台灯、热茶 |

## 三、节奏技巧（让短句有"金句感"）

1. **用具体名词代替抽象形容**：「很孤独」→「第二杯半价的奶茶没人分」。
2. **用数字制造真实感**：「翻了37条消息，最后一条停在三个月前。」
3. **结尾留动词或意象，不留结论**：不写"我好难过"，写"关了灯，影子里都是你"。
4. **对比结构**：「白天笑得最大声，晚上最安静。」
5. **省略主语**：伤感文案常省"我"，更代入。「又是一个人」比"我又是一个人"更走心。

---

## 四、emoji 使用规则

- 克制留白、破防直给：**不用 emoji**，靠文字。
- 治愈反转：**最多 1 个**，且只用柔和的（如 🌙 ☔ 🍂 ☕），不用 😭 💔 这类过浓的。
- 一组文案里 emoji 风格统一，不混用。

## 五、红线清单（禁用词与禁用方向，生成时必须规避）

### 5.1 绝对禁用内容（命中即停止生成并提示）
- 自残、自杀、暴力、伤害身体的任何暗示或美化（如"划""了结""消失算了"相关美化表述）。
- 低俗、色情、辱骂、人身攻击。
- 涉政、地域/性别/民族引战、歧视性表述。
- **伪托编造**的名人名言/古诗（如把假句子署名"村上春树""李清照"）。**注意**：真实存在、确有出处的古诗词名句允许引用并标注出处（见 SKILL.md 原则1）；成语典故自由使用。

### 5.2 风格禁用（影响质量但不踩线，生成时规避）
- 非主流长难句、过度堆砌辞藻（如"那一年樱花落满整个青春的斑驳"）。
- 滥用英文/拼音/火星文（如"sad""emo boy"穿插）。
- 假大空的鸡汤口号（如"你要坚强""明天会更好"作为结尾）。
- 过度密集的感叹号、省略号（一条文案最多 1 个感叹号或 1 组省略号）。

### 5.3 当用户输入踩线时的处理
1. 不生成踩线内容；
2. 输出一句温和提示："这个方向我帮不了你写，换个角度试试？"
3. 给一句转向治愈方向的备选（如把"消失算了"转向"先去睡一觉，明天再说"）。

### 6.5 引用规则提醒
- **真实名句**：上表所列均可引，标注出处。
- **民间成语/谚**（如"情深缘浅""落花有意"）：古意浓、无版权风险，可自由使用，标"古谚"。
- **原创仿古**：确无贴合真实句时，可写对仗工整的仿古句，**必须标"原创·仿古"**，绝不伪托古人。

## 七、现代诗/古诗结合手法（隐隐表达的第5种手法）

> 用户建议：语境到了可适当用古代史/现代诗结合伤感文案。沉淀为以下用法。

### 7.1 现代诗化比喻（用于"X是___"长句填空）
当骨架是"缘分是/爱是/孤独是___"这种**定义句**，填一个**本体+延伸排比**的长比喻，比短词更走心：
- 缘分是→**一本书，翻得太快会错过，读得太认真，又流泪**。（书为本体，翻/读为延伸）
- 孤独是→**一盏灯，亮着没人看，灭了没人问**。
- 想念是→**一场雨，下的时候你没带伞，停了你还在等**。

结构公式：「X是 +【一个具象本体】，【两个对仗的延伸动作 + 后果】」。

### 7.2 古诗 + 白话混搭（语境到了才用）
当文案需要文学张力时，可在白话中嵌一句真实古诗/成语，制造文白反差：
- "后来才懂'此情可待成追忆'，可惜当时只当是寻常。"
- "你说缘分'落花有意'，我偏要'流水长情'。"
**注意**：嵌入的古诗必须是真实名句，不伪托；混搭要自然，不生硬堆砌。

### 7.3 何时用古诗/现代诗结合（判定门槛）
- 骨架本身古风 → 用古诗/对仗（必选）。
- 骨架是文学化长句（如"缘分是___"）→ 用现代诗化比喻。
- 骨架是日常口语 → **不要硬塞古诗**，用朴素陈述（过度文艺反而失败，见0.3反例）。

## 八、押韵与韵味（中国语言文化核心，最高优先级之一）

> 中文好文案的两大支柱：**意对**（隐隐表达）+ **音谐**（押韵出韵味）。
> 押韵是把"意思到位的句子"提升为"念念不忘的金句"的关键。古诗之所以流传千古，一半靠押韵。
> **生成对仗/并列/回环/排比句式时，尾字押韵是硬性考量，押韵版优先于不押韵版。**

### 8.1 何时必须押韵

| 句式 | 是否押韵 | 说明 |
|------|---------|------|
| 对仗句（眼泪是X，执念是Y） | **必须** | 前后两半尾字押韵，回环感最强 |
| 排比句（孤独是X，想念是Y，遗憾是Z） | **必须** | 多个分句尾字同韵，气势连贯 |
| 回环句（念起是风，念落是空） | **必须** | 内部自押，韵味核心 |
| 同主题成组文案（如一组排比短句） | **建议** | 末字同韵，整组读起来像一首诗 |
| 独立单句（无对仗） | 不强求 | 能自押更好，不能也无妨 |

### 8.2 押韵操作步骤（对仗/并列句必走）

1. **标出前半句尾字的韵母**（按拼音）。
2. **填空尾字选同韵母或近韵的字**。
3. **优先级**：同韵母 > 近韵（韵腹相同韵尾不同）> 声调协调（仄对平）> 节奏对称（字数同）。

### 8.3 常见韵母速查表（填空选尾字用）

| 韵母(拼音) | 常用字（适合伤感文案） |
|-----------|---------------------|
| **ie/ue** (血/结) | 血(xuě)、结(jié)、灭(miè)、缺(quē)、月(yuè)、别(bié)、劫(jié)、雪(xuě)、绝(jué)、切(qiè)、裂(liè) |
| **an/ian/uan** (寒/前) | 寒(hán)、散(sàn)、远(yuǎn)、念(niàn)、叹(tàn)、散(sǎn)、岸(àn)、憾(hàn)、断(duàn)、浅(qiǎn) |
| **ing/eng** (影/风) | 影(yǐng)、风(fēng)、空(kōng)、梦(mèng)、醒(xǐng)、冷(lěng)、声(shēng)、城(chéng)、灯(dēng) |
| **i/ü** (离/雨) | 离(lí)、雨(yǔ)、寂(jì)、忆(yì)、泣(qì)、息(xī)、许(xǔ)、局(jú)、去(qù) |
| **ao/iao** (老/小) | 老(lǎo)、少(shào)、早(zǎo)、草(cǎo)、岛(dǎo)、了(le轻声/liǎo)、抱(bào) |
| **ou/iu** (愁/秋) | 愁(chóu)、秋(qiū)、留(liú)、走(zǒu)、旧(jiù)、休(xiū)、酒(jiǔ) |
| **u** (无/苦) | 无(wú)、苦(kǔ)、误(wù)、负(fù)、独(dú)、哭(kū)、路(lù) |
| **a/ia/ua** (花/家) | 花(huā)、家(jiā)、涯(yá)、差(chà)、假(jiǎ)、话(huà)、疤(bā) |

### 8.4 经典押韵范例（黄金标杆，生成时参照）

**对仗押韵（ie/ue 韵）**：
- 眼泪是透明的**血**(xuě)，执念是解不开的**结**(jiē)。⭐用户黄金答案
- 相思是无声的**劫**(jié)，回忆是不愈的**裂**(liè)。

**对仗押韵（an 韵）**：
- 聚散是天意难**违**，得失是人心不**悔**。（ue/ui 近韵）
- 来是春**风**，去是秋**空**。（ong/eng 韵）

**回环自押**：
- 念起是**风**，念落是**空**。（ong 韵）
- 得之我**幸**，失之我**命**。（ing 韵）

**排比押韵（同主题成组短句用）**：
- 孤独是热闹里的**哑巴**(ba)，想念是戒不掉的**伤疤**(ba)，遗憾是没说完的**情话**(huà)。（a 韵）

### 8.5 押韵自检（过自检闸时必加一项）

生成对仗/排比句后，**大声念一遍**：
- 尾字押韵、读起来有回环感 → 通过。
- 尾字不押韵、读起来干巴 → **换同韵字重写**（哪怕语义稍让步，也要保韵味）。
- **例外**：若骨架是日常口语白话（如"人好像丢了东西后，___"），押韵会让位给"朴素自然"，不强押，否则像打油诗。古风/文学化骨架才必押。
